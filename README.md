\# Real Time Stress Monitoring System



\## Overview



A real-time stress monitoring system using ESP32, MAX30100 Pulse Oximeter, DS18B20 Temperature Sensor, and GSR Sensor. Sensor data is transmitted to Firebase Realtime Database and visualized through a web dashboard.



\## Features



\* Heart Rate Monitoring

\* SpO₂ Monitoring

\* Body Temperature Monitoring

\* Galvanic Skin Response (GSR) Monitoring

\* Real-Time Firebase Integration

\* Stress Level Estimation

\* Interactive Dashboard



\## Hardware Used



\* ESP32

\* MAX30100 Pulse Oximeter

\* DS18B20 Temperature Sensor

\* GSR Sensor



\## Software Used



\* Arduino IDE

\* Firebase Realtime Database

\* HTML

\* CSS

\* JavaScript
